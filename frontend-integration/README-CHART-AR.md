# 📊 دمج الشارت الاحترافي في الفرونت — دليل خطوة بخطوة

> **الهدف:** شارت بنمط TradingView — شموع حقيقية كاملة، والتمرير لليسار يجلب
> الشموع الأقدم تلقائيًا **بلا أي حد لعدد الشموع**، مع بث حي للسعر.

---

## 1) التثبيت (خطوة واحدة)

في مجلد مشروع الفرونت:

```bash
npm install lightweight-charts
```

ثم انسخ ملف **`TradingChart.tsx`** (الموجود بجانب هذا الدليل) إلى مجلد
المكونات عندك، مثل: `src/components/TradingChart.tsx`

---

## 2) الاستخدام

```tsx
import TradingChart from "./components/TradingChart";

function CurrenciesPage() {
  return (
    <TradingChart
      apiBase="http://161.97.73.254:8000"   // عنوان الباك (أو نفس الدومين إن كان خلف بروكسي)
      symbol="BTCUSDT"
      market="crypto"
      timeframe="1h"
      height={560}
      onStatusChange={(s) => console.log(s.loadedCandles, s.live, s.state)}
    />
  );
}
```

**خصائص المكون:**

| الخاصية | النوع | الافتراضي | الوصف |
|---|---|---|---|
| `apiBase` | string | `http://localhost:8000` | عنوان خادم الباك |
| `symbol` | string | `BTCUSDT` | الرمز الابتدائي (يُستبدل من حقل الإدخال بالشارت) |
| `market` | string | `crypto` | `crypto` أو `stocks` |
| `timeframe` | string | `1h` | `1m 5m 15m 1h 4h 1d` |
| `height` | number | `520` | ارتفاع منطقة الرسم |
| `onStatusChange` | function | — | يُخبرك بعدد الشموع المحمّلة وحالة البث |

---

## 3) ماذا يفعل المكون خلف الكواليس؟

1. **التحميل الأولي:** يطلب آخر 2000 شمعة مغلقة:
   ```
   GET {apiBase}/api/v1/market/candles/crypto/BTCUSDT?timeframe=1h&limit=2000
   ```
2. **تعبئة مسبقة:** يجلب صفحتين إضافيتين (4000 شمعة) خلف الكادر —
   فلا يرى المستخدم فراغًا أبدًا عند أول تمرير.
3. **التمرير لليسار:** عندما يقترب المستخدم من أقدم شمعة محمّلة (بمقدار 80 شمعة)
   يطلب الصفحة الأقدم تلقائيًا:
   ```
   GET ...&before=<أقدم وقت محمّل بالملي ثانية>
   ```
   ويكرر ذلك **بلا نهاية** حتى بداية تاريخ الرمز (عندها يظهر "بداية التاريخ").
4. **البث الحي:** يتصل بـ `WS {apiBase}/ws/live/crypto/BTCUSDT?timeframe=1h`
   ويحدّث آخر شمعة لحظيًا؛ إن لم يتوفر WS يسقط تلقائيًا إلى تحديث دوري كل 15 ثانية.

> ⚠️ **لا يوجد أي حد إجمالي على عدد الشموع** — الحد الوحيد هو حجم الصفحة
> الواحدة (2000 شمعة) وهو لأداء الشبكة فقط، والتاريخ كله متاح بالتمرير.

## 4) إذا كان فرونتك يستخدم صفحات/مسارات أخرى للرموز

اربط حالة صفحة العملات بالمكون مباشرة:

## 5) CORS — مهم!

الباك يسمح فقط للعناوين المصرّح بها في `.env` → `CORS_ORIGINS`.
تأكد أن عنوان فرونتك موجود، مثلًا:

```
CORS_ORIGINS=["http://161.97.73.254:3018","http://localhost:3018","http://localhost:3000"]
```

ثم أعد تشغيل الباك (`docker compose restart backend`).

---

## 6) جرّبه فورًا بدون أي كود!

الباك يقدم شارتًا جاهزًا يعمل بنفس المنطق على:

```
http://localhost:8000/demo/chart.html
```

افتحه من المتصفح بعد تشغيل الباك — نفس المحرك والمنطق المستخدم في `TradingChart.tsx`.

---

## 7) استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| الشارت فارغ | افتح DevTools → Network وتأكد أن نداء `/api/v1/market/candles/...` يعيد 200 |
| `CORS policy` | أضف عنوان الفرونت إلى `CORS_ORIGINS` في `.env` وأعد تشغيل الباك |
| الشموع لا تُحمّل عند التمرير | تأكد أن `has_more: true` في الرد، وأن نداءات `before=` تعيد 200 |
| البث الحي لا يعمل | لا مشكلة — المكون يتحول تلقائيًا للتحديث الدوري كل 15 ثانية |
| أول تحميل بطيء | طبيعي في أول طلب (تنزيل من Binance)؛ بعدها يعمل الكاش على القرص فورًا |
