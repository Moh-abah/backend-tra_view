# مختبر الإثبات R45 (Proof Lab)

هذا المجلد بيئة إثبات **مستقلة تماماً** — تعيد إنتاج الإثبات الحي 34/34
الذي سُلّم مع الحزمة، بلا الحاجة لمشروعك الكامل:

- ملفات **الراوترات والخدمات والنماذج هنا هي ملفات R45 الفعلية** نفسها
  (منسوخة حرفياً من جذر الحزمة — بصمات متطابقة في MD5SUMS).
- **ستُبّات المحرك فقط** (engine1/unified_backtest/exit_strategy/...)
  تحاكي عقد محركك الحقيقي بحسم — لأن ملفات محركك محروسة في مصدرك ولم
  تكن متاحة أثناء البناء. الستُبّات معلَّمة بوضوح في رؤوسها.

## التشغيل

```bash
cd proof-lab
python3 prove_r45.py
# ← خلاصة الإثبات الحي R45: 34/34
```

السكربت يدير سيرفره الخاص (منفذ 8115، قاعدة مؤقتة، ساعة مجمّدة
للتحكم في سيناريوهات الكاش) ويغلق كل شيء بعده.

## نقطة نهاية تحكم اختبارية (ساندبوكس فقط)

`POST /sandbox/_test/control` — تتيح تقديم الساعة المجمّدة وتباطؤ
المحاكاة أثناء التشغيل لأغراض الإثبات. **غير موجودة في ملفات الإنتاج**
الموجودة في `app/` بجذر الحزمة — فقط في `proof-lab/app/`.
